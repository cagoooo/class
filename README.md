# 班級小管家 📚

一個功能完整的班級管理工具，專為教師設計。

## 功能特色

### 核心功能
- 👥 **學生管理** - 新增、編輯、刪除學生資料
- ⭐ **加扣分系統** - 即時加減分與歷史記錄
- 🎲 **抽籤系統** - 單人/多人/分組抽籤
- 👨‍👩‍👧‍👦 **隨機分組** - 自動分組功能
- ⏰ **計時器** - 倒數/正數計時
- 📝 **聯絡簿** - 聯絡事項管理
- 📋 **作業檢查** - 作業繳交狀態追蹤
- 🏆 **排行榜** - 即時分數排名
- 🕐 **全螢幕時鐘** - 多種樣式時鐘

### v2.0 新增
- ☁️ **Firebase 雲端同步** - 資料雲端備份
- 📊 **科目分類** - 作業科目標籤
- 🔴 **優先級標記** - 聯絡簿優先級

## 快速開始

1. 開啟 `classnew.html`
2. 新增學生資料
3. 開始使用各項功能

## 技術棧

- HTML5 + JavaScript
- Tailwind CSS
- Firebase Firestore
- SheetJS (Excel 處理)
