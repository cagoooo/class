# 班級小管家 📚

🌐 **線上使用：[班級小管家](https://cagoooo.github.io/class/)**

> 📌 **目前版本：v3.24.0**（依據 `CHANGELOG.md`）

一個功能完整的班級管理工具，專為教師設計。

## 功能特色

### 核心功能
- 👥 **學生管理** - 新增、編輯、刪除學生資料
- ⭐ **加扣分系統** - 即時加減分與歷史記錄
- 🎲 **抽籤系統** - 單人/多人/分組抽籤
- 👨‍👩‍👧‍👦 **隨機分組** - 自動分組功能
- ⏰ **計時器** - 倒數/正數計時
- 📝 **聯絡簿** - 聯絡事項管理
- 📋 **作業檢查** - 作業繳交狀態追蹤
- 🏆 **排行榜** - 即時分數排名
- 🕐 **全螢幕時鐘** - 多種樣式時鐘

### v2.0 新增
- ☁️ **Firebase 雲端同步** - 資料雲端備份
- 📊 **科目分類** - 作業科目標籤
- 🔴 **優先級標記** - 聯絡簿優先級

## 快速開始

1. 開啟 `classnew.html`
2. 新增學生資料
3. 開始使用各項功能

## 技術棧

- HTML5 + JavaScript
- Tailwind CSS
- Firebase Firestore
- SheetJS (Excel 處理)

## 🛠️ 開發與安全性規範

為了確保 Firebase API Key 不會意外外洩至 GitHub，本專案採用「編譯時佔位」機制。

### 本地開發指令
- **套用金鑰**：`npm run dev:apply` (讀取 `.env` 並注入金鑰)
- **還原佔位符**：`npm run dev:restore` (將金鑰替換回佔位符，**Push 前必跑**)

> [!CAUTION]
> 在執行 `git push` 之前，請務必確認已執行 `npm run dev:restore`！
