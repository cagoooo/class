# 寵物與資料保護驗收

- 測試方式：正式 GitHub Pages，Chrome 關閉 HTTP 快取與略過 Service Worker 讀取新版；離線重載測試時重新啟用快取。未清除使用者網站資料。
- 測試資料：隔離 sessionStorage 的 48 位虛構學生。雲端測試班 safety-qa-20260922-336；不寫正式班級目錄。
- 72 項 Node 回歸測試通過：42 寵物、23 資料保護、7 同步入口。
- Blender MCP：重做四階段彩色蛋，實際渲染 WebP；電腦成長卡片 168 × 189px，手機精簡列 88 × 99px。
- 圖鑑：0／30 時無寵物圖像節點；3、6、9 成長值依序顯示三階段破殼，10 時抽到猴子，變成 1／30、29 格問號。
- 解鎖詳情：三種成長造型及三種表情圖片皆載入成功；重新載入仍保留 1／30。
- RWD：Chrome 模擬 320、390、768、1024、1440 CSS px，圖鑑無水平溢出；320px 可點擊解鎖詳情與返回。並非五台實體裝置測試。
- 減少動態效果：蛋及孵化寵物 computed animation 均為 none。
- Excel：實際 XLSX 二進位寫入／讀回逐欄一致；下載至 Downloads，再從選檔器匯入。48 人、51 筆紀錄、第一位成長 17／金幣 11、1 項商品、2 種圖鑑還原一致。
- 同步：兩個隔離分頁模擬不同裝置，A 完整版本可由 B 還原。A 離線新增並重載後保留資料；B 新增並上傳後，A 恢復連線上傳被衝突保護攔截。
- 衝突：320px 五個操作按鈕均 50px 高；下載兩份 JSON、勾選確認後可選雲端版本，原本機副本可下載。兩分頁最後均為 synced，48 人／51 筆／圖鑑 2／30。
- 初次實測發現 Firestore DocumentReference 不支援 doc()，已修正為 collection().doc()，測試替身也加入此限制。
- Firebase 三個後台保護函式已部署：getAdminStats、getTeacherOrphanDetails、purgeDeletedClassLeftovers。

限制：全班同步衝突驗收使用兩個 Chrome 分頁，未使用兩台實體裝置。還原前副本在 IndexedDB，與一般網站資料同受清除影響；重要成果仍應下載。所有裝置需更新新版才能共同使用版本衝突保護。
